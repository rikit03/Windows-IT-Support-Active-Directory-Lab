
# Windows IT Support & Active Directory Homelab

> Hands-on IT support lab focused on Windows administration, Active Directory, user and access management, troubleshooting, and help desk documentation.

## 📌 Project Overview

This project is a hands-on Windows IT support homelab designed to simulate common Level 1 Service Desk and IT Support tasks in a small business environment.

The goal is to build practical experience with Windows systems, Active Directory, user administration, permissions, troubleshooting, and technical documentation.

The lab follows a structured support methodology:

**Identify → Investigate → Troubleshoot → Resolve → Verify → Document**

> **Note:** This is a personal homelab and simulated support environment. No production systems or real customer data are used.

---

## 🎯 Objectives

- Build a Windows-based support environment
- Practice Windows administration
- Learn and demonstrate Active Directory administration
- Create and manage users and security groups
- Practice password and account troubleshooting
- Configure permissions and shared resources
- Troubleshoot Windows and network connectivity issues
- Document incidents using a help desk ticket format
- Develop professional troubleshooting and documentation habits
